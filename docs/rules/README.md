# Règles détaillées

Ce dossier contient les spécifications normatives utilisées pour écrire les
tests RED. En cas d'ambiguïté avec un résumé du README, ces documents détaillés
font foi pour la version qu'ils annoncent :

- [`game-rules-v1.md`](./game-rules-v1.md) — règles de jeu `1.0.0`, machine à
  états, événements, erreurs et table de décision ;
- [`account-and-data-v1.md`](./account-and-data-v1.md) — parcours de compte,
  pseudonyme, préférences, résultats, autorisation et données v1.

Une évolution observable des règles de jeu change leur version et commence par
une modification de la spécification puis des tests RED.
